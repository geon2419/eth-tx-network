# Ethereum Transaction Network

- 이더리움 트랜잭션 기반 그래프 시각화 시뮬레이션
- TypeScript, WebGPU, Web Worker, Cytoscape.js, echarts 사용
- WebGPU 병렬 연산으로 Force-directed 레이아웃 최적화 실험

## Getting Started

[Bun](https://bun.sh/)이 설치되어 있는지 확인하세요.

```bash
bun install
```

```bash
bun run dev
```

브라우저에서 `http://localhost:3000` 열기
